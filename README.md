
# 🥖 Padaria Nova

Website de padaria desenvolvido com foco em design, organização e experiência do usuário.

## 📌 Sobre o projeto

O Padaria Nova é um projeto de desenvolvimento web que busca apresentar uma padaria por meio de uma interface moderna, intuitiva e visualmente agradável.

O projeto faz parte do meu portfólio de desenvolvimento de software, com foco na criação de soluções web para pequenos negócios.

## 🎯 Objetivos

- Desenvolver uma interface intuitiva e organizada.
- Aplicar conceitos de desenvolvimento front-end.
- Praticar HTML, CSS e JavaScript.
- Criar uma presença digital para um pequeno negócio.
- Desenvolver habilidades práticas de programação.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🚀 Como executar

Clone o repositório:

```bash
git clone https://github.com/thierry-572/padaria-nova.git
```

Entre na pasta do projeto:

```bash
cd padaria-nova
```

Abra o arquivo `index.html` no navegador.

## 📂 Estrutura do projeto

```text
padaria-nova/
├── index.html
├── style.css
├── script.js
└── README.md
```

> A estrutura acima é ilustrativa. Ajuste os nomes conforme os arquivos reais do projeto.

## 📚 Aprendizados

Este projeto permite praticar o desenvolvimento de interfaces web, a organização de arquivos e a aplicação de conceitos fundamentais de HTML, CSS e JavaScript.
